FAZA 2 — Pametno dodavanje igara

Ovo je deo koji smo poslednji put posebno razmatrali.

5. Automatsko prepoznavanje igre

Kada korisnik doda .exe:

Aplikacija dobija putanju do executable-a
Prepoznaje igru
Automatski pokušava da pronađe:
Title
Genre
Description
Cover
Developer
Publisher
Release date

Korisnik ne mora ručno da popunjava sve podatke.

6. Offline-first ponašanje

Ovo je važna funkcionalnost koju smo definisali.

Ako korisnik nema internet:

Add Game
    ↓
Select .exe
    ↓
Game detected
    ↓
No Internet
    ↓
Game added immediately
    ↓
Basic metadata saved locally

Kada se internet kasnije pojavi:

Application starts
    ↓
Internet available
    ↓
Find games with missing metadata
    ↓
Fetch metadata automatically
    ↓
Update games.json
    ↓
Refresh UI

Dakle:

Igra se nikada ne blokira zbog nedostatka interneta.

Biblioteka radi lokalno, a metadata se dopunjava kada internet bude dostupan.

10. Metadata pipeline

Napraviti centralizovani sistem:
